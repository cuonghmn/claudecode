Hướng dẫn sử dụng tự diễn

Nên làm theo thứ tự

  • Xem hướng dẫn sử dụng trước 5 phút để biết app làm được gì.
  • Cài đặt theo hướng dẫn 1, chạy phần kiểm tra 5 phút ở cuối.
  • Dùng thật 2 tuần, sau đó gửi mẫu báo cáo (có trong bước 13) cho Claude.

Trong thư mục code

  • Code.gs, Index.html, appsscript.json: 3 file của app (đã nhúng sẵn trong hướng dẫn cài đặt).
  • README.md: mô tả kỹ thuật, cấu trúc dữ liệu, các thuộc tính cài đặt.
  • docs/: bộ tài liệu này. Tạo lại bằng node expense-tracker/mockup/build.js && node expense-tracker/docs/build.js.
